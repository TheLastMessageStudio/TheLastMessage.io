Le tafsir de chaque verset à portée de main

Dans la lecture du Coran, appuyez sur un verset pour consulter son tafsir et approfondir sa compréhension.

Chaque verset peut être sélectionné individuellement afin d’ouvrir son explication (tafsir) directement dans l’application, sans devoir chercher manuellement le commentaire correspondant.

Comment télécharger l’application ?

Suivez ces quelques étapes sur votre téléphone Android.

1

Ouvrir la page de téléchargement

Appuyez sur « Télécharger l’application Android » pour ouvrir la dernière version publiée sur GitHub.

2

Télécharger le fichier APK

Dans la section Assets, appuyez sur app-release.apk et attendez la fin du téléchargement.

3

Installer l’application

Ouvrez le fichier téléchargé. Si Android le demande, autorisez temporairement l’installation depuis ce navigateur, puis appuyez sur Installer.

À savoir

Pour mettre à jour l’application, installez le nouvel APK par-dessus la version déjà installée. Ne désinstallez pas l’ancienne application : cela peut supprimer vos données locales. Android peut afficher un avertissement avant l’installation d’un APK téléchargé hors du Play Store.
